# NurseConnect

Starter scaffold for NurseConnect: React + TypeScript frontend (Vite) and Node + Express backend (TypeScript).

Quick start

- Frontend:
  - cd client
  - yarn install
  - yarn dev

- Backend:
  - cd server
  - yarn install
  - yarn dev

Configure server env with `.env` (see `.env.example`).
